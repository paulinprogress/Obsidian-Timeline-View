# Timeline View

Timeline View adds a horizontal timeline layout to Obsidian Bases.

## Use

1. Enable the Bases core plugin and create or open a Base.
2. Add a **Timeline** view.
3. Open the view options and choose a frontmatter property for **Start date**.
4. Optionally choose an **End date** to display notes as date ranges. Without an end date, notes appear as milestones.

Dates should use ISO format, such as `2026-04-15`. Timeline entries link to their notes. Bases grouping and sorting are respected.
